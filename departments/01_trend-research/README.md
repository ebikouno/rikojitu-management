# 部門1: 競合・トレンド分析部門 業務マニュアル

エージェント: `trend-researcher`

## ミッション
@riko_jitu の方針・ペルソナに合う「次に作るべき動画」の材料を外部から集める。

## 定常業務
| 業務 | 頻度（仮） | 出力先（プラットフォーム） |
|------|-----------|----------------------------|
| 競合アカウント定点観測（フォロワー・直近リールの伸び） | 週1 | 競合・トレンド分析 / 競合トラッカー（シート） |
| アウトライヤー（平均より大きく伸びた動画）探索 | 週1 | 競合・トレンド分析 / 週次トレンドレポート |
| ネタ候補の追加 | 週1（5〜10件） | 2 アイデア帳 / ネタ帳 |
| 新規競合候補の提案 | 月1 | 週次レポート内「競合リスト追加提案」 |
| トレンド音源・季節イベントの確認 | 週1 | 週次トレンドレポート |

※頻度は `docs/open-decisions.md` で確定させる。

## 分析の観点
1. **フック**: 冒頭1〜3秒で何を見せ／言っているか
2. **構成**: 起承転結、情報の出し方、オチ
3. **尺・テンポ**: 秒数、カット数
4. **見た目**: テロップ量・フォント・画角・出演人数
5. **音**: トレンド音源か、地声か、BGMか
6. **CTA**: 保存・フォロー・コメントを促す仕掛け
7. **反応**: 再生／フォロワー比、コメントの傾向
8. **@riko_jitu への転用案**: 何を残し、何をオリジナルにするか

## ネタ帳への記入項目
ID / 追加日 / 追加者（部門1 or メンバー名）/ ネタ概要 / 参考URL / 想定フック / ペルソナ適合度(1-5) / 実現難易度(1-5) / ステータス（候補・採用待ち・台本化済・投稿済・見送り）
