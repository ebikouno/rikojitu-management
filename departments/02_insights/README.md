# 部門2: 自身のInstagram分析部門 業務マニュアル

エージェント: `insights-analyst`

## ミッション
@riko_jitu の実績データから「何が効いて、何が効いていないか」を明らかにし、方針の改善を提案する。**変更は実行しない。**

## データ取得方法（優先順）
1. vidIQ の Instagram 連携（`vidiq_instagram_owner_insights`）— 要: プロアカウント（ビジネス/クリエイター）化と vidIQ 連携
2. 公開データ（`vidiq_ig_profile` / `vidiq_ig_profile_reels`）— 再生数・いいね・コメント等の公開値のみ
3. 手入力シート — メンバーが Instagram アプリのインサイト画面から転記

## 追跡する指標（案）
| 区分 | 指標 |
|------|------|
| アカウント | フォロワー数・増減、リーチ数、プロフィールアクセス、外部リンクタップ |
| 投稿（リール） | 再生数、リーチ、平均視聴時間、視聴維持率、いいね、コメント、保存、シェア、フォロー転換数 |
| 属性 | 年齢・性別・地域、アクティブ時間帯 |
| 派生指標 | 保存率・シェア率（÷リーチ）、再生/フォロワー比、フォロー転換率 |

※KPI と目標値は `docs/open-decisions.md` で確定させる。

## 定常業務
| 業務 | 頻度（仮） | 出力先 |
|------|-----------|--------|
| 投稿の数字の追記（72時間・7日） | 投稿ごと | 3 分析 / 投稿の数字 |
| 週次分析レポート | 週1 | 自アカウント分析 / 週次レポート |
| 月次振り返り＋方針提案 | 月1 | 自アカウント分析 / 月次レポート、提案ログ |
| 30本ごとの配分見直し提案 | 30本ごと | 2 アイデア帳 / 方針の変更提案 |

## 提案の書き方
提案ID / 日付 / 提案内容 / 根拠データ / 期待効果 / 検証方法と期間 / 優先度(高中低) / ステータス（提案中・採用・見送り）※ステータス変更はオーナー判断
