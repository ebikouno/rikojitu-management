# 部門3: 台本作成部門 業務マニュアル

エージェント: `script-writer`

## ミッション
分析結果と過去の成功パターンにもとづき、3人がすぐ撮影できる台本を作る。

## 承認フロー
```
依頼（オーナー → リーダー → 部門3）
  → 台本案作成（2 アイデア帳「台本案を書く」に「承認待ち」で保存）
  → リーダーがオーナーに提示 → 3人で採否を決定（取りまとめ：ちゃむ）→ オーナー経由で結果を受け取る
      ├ 採用    → 部門3が「1 決定事項 → 採用台本」に記入、変更履歴に記録
      ├ 修正依頼 → 版を上げて再提出（v1 → v2）
      └ 不採用  → 理由を記録して「見送り」
```
明示的な「採用」の連絡以外では採用台本に記入しない。

## 台本に必ず含める項目
- タイトル（管理用）／版数／作成日／ネタ帳ID
- 狙い（ペルソナ・目的: 認知 / 保存 / フォロー獲得 など）と根拠（どの分析結果に基づくか）
- フック案 2〜3 パターン
- 本編: 秒数ごとのカット・セリフ・テロップ・画面指示
- 尺・音源案・CTA
- キャプション案・ハッシュタグ案・投稿推奨日時
- 撮影メモ（出演者・場所・小道具）

## 参照する情報
方針・ペルソナ / 過去の採用台本・過去台本と成績（3 分析 → 投稿の数字）/ 最新の自アカウント分析 / 最新のトレンドレポート / ネタ帳
