# 毎日の台本案（2026-10-21〜、ろん指示）

毎日3本：**オリジナル1本＋進行中シリーズの続編2本**。共有フォルダ（Drive）に上げる前に、必ずろんに通知して確認をもらう。

## 手順
1. 読む
   - `docs/drafts/series-tracker.md`（次に作る回・次の台本ID・回し方）
   - `docs/data/past_scripts.json`（過去台本37本。続編は主にこれを参考にし、シリーズの型・セリフ回しを崩さない）
   - `docs/data/insights_2026-10-20.json`（全94本の成績）と `docs/drafts/` の過去の台本案（ネタの重複を避ける）
   - `docs/reference/persona-guide-2026-10-20.md`（方針・ペルソナ・制作ルール）、`templates/script.md`
   - Drive コネクタがあれば、台本ノート（1zT9BE9tOdKbExobNzQXmI-5zBNLNDOJgJJnWx1XmiM4）のろんの編集・コメントも読み、直しの傾向を反映する（例: 関西弁を減らす、説明的なセリフを短くする）。**Drive には書き込まない。**
2. 書く: `docs/drafts/YYYY-MM-DD_台本案.md`（形式は `docs/drafts/2026-10-20_台本案.md` と同じ。タイトル／種別／第一ペルソナと理由／フック案2〜3／本文（役：セリフ（動き）【テロップ】、30〜40秒）／オチ／撮影メモ／キャプション案／採点4項目／見たい指標）。作成者表記は「ろん」。
3. 更新: `docs/drafts/series-tracker.md` の「台本済みの最新」「次に作る回」「次の台本ID」「作成ログ」。
4. commit して push（`git push -u origin HEAD`）。
5. ろんに通知（セッションの最終報告。プッシュ通知が届く）: 冒頭に結論 → 3本の一覧（ID・タイトル・種別・誰向け・採点）→ 各本の本文 → 判断してほしい点。
6. **Drive（台本ノート・アイデア帳）への反映は、ろんの OK を受けてから**（ろんがそのセッションか管理セッションで指示する）。反映するときは台本ノートに「（管理用シートに反映済み）」付きで追記し、アイデア帳「台本案を書く」に「承認待ち」で行を追加する。
