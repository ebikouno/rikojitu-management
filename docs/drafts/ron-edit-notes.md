# ろんの直しの傾向（毎日の台本案で反映する）

台本ノートでろんが直した内容から読み取った傾向。毎日の台本案を作る前に読み、台本ノートの最新の編集・コメントを見て更新する。

## 2026-10-21 時点（S-001〜S-006 の編集から）

| 傾向 | 例（元の案 → ろんの直し） |
|---|---|
| 時期の見出し・説明テロップを減らし、場面をシンプルにする | S-001：【1年4月 新歓】などの見出しや【何入試？＝…】のテロップを削除し、画面外の質問だけで場面を切り替えた |
| 質問はインタビュー風の丁寧語にする | S-001：「2人って何入試なん？」→「入試方法を教えてください」「大学の成績を見せてください」 |
| オチの後のひと言を削り、相手の一言で終える | S-001：最後の「受験の延長戦、ここでも負けてるやん」を削除し、れんとの「定期テストは6年間やってきたから」で終える |
| 実際の大学生活に寄せたリアルなディテール | S-003：「レポート1万文字」「提出後に試問」「持ち込み禁止」「授業の感想文だけ」。S-001：「今年の数学むずかったけど良い問題多かった」 |
| 関西弁を減らし、標準語を混ぜる | S-003・S-004：「〜あるやろ」→「〜あるだろ」、「足りへん」→「足りない」 |
| セリフを短く、つなげる | S-004：余白の場面と前日の場面を1〜2行にまとめた |
| 小道具に頼る演出（名札など）より、2人の演技で見せる | S-003：名札の受け渡しを削除し「冒頭にちゃむとれんとが文理の役回りを変える演技をいれる」に |
| 参考動画を撮影メモに入れる | S-001：参考にする他アカウントの動画URLを追記 |
| 誇張しすぎたオチは「しんどい」リアルさに | S-006：「ねみ～」→「眠すぎる、、今日の授業大事だし行かなきゃよかった、、」 |

## ろんのコメント（気にしていること）
- 過去の動画とネタが似ていないか（S-004「模試の結果、似たのやったことあったかも」）→ 続編は過去台本・投稿タイトルと照合して重複を避ける。
- 時系列で並べる構成もあり（S-004「模試前日→模試中→結果」）。
- 尺が短すぎないか（S-005「尺短すぎ？」）→ 30〜40秒を目安に、場面は3つ以上。
- 冒頭の作り方（S-003「冒頭の台本どうしよ」）→ 冒頭3秒の案を具体的なセリフ・動きまで書く。
- 未完成の案は「未完成」とされる（S-002）→ 1本ごとに完成度を上げ、オチまで書き切る。
