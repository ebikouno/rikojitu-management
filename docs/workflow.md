# 運用フロー（たたき台）

> 曜日・時刻は仮。`docs/open-decisions.md` で確定後に更新し、定期実行（スケジュールタスク）を設定する。

## 週次サイクル
```
[月] 部門2: インサイト取得 → 投稿の数字（3 分析）に追記 → 週次レポート ┐
[月] 部門1: 競合定点観測・アウトライヤー探索 → トレンドレポート ┘（並列）
        ↓
[火] リーダー: 両レポート＋意見・やりたいことを統合 → 週次サマリー → オーナーへ報告
        ↓
[火〜水] 部門3: 台本案を作成 → リーダー経由でオーナーに採否確認
        ↓
[承認後] 部門3: 採用台本に記入 → 3人が撮影・投稿
```

## 月次サイクル
- 部門2: 月次振り返り＋方針変更提案（提案ログ）
- 部門1: 競合リストの見直し提案
- リーダー: 3人の方針・やりたいことの棚卸し、方針シート更新案の作成（確定はオーナー）

## 随時
- オーナーからの依頼 → リーダーが振り分け
- 投稿後48時間チェック（任意）

## 定期実行の実装方法
Claude Code のスケジュールタスクで、このリポジトリを開いた新規セッションに以下のようなプロンプトを送る:
```
週次定例を実行して。部門1と部門2を並列で回し、結果をプラットフォームに記入、
週次サマリーを作成して報告して。台本は作らず、ネタ候補のみ提示すること。
```
