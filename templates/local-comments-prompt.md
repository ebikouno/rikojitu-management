# ローカルチャット用プロンプト（Instagram コメントの読み取り）

クラウドのセッションからは Instagram に接続できず、vidIQ にも Instagram のコメントを取る機能がないため、Claude デスクトップアプリ（Claude in Chrome が使える環境）で、ログイン済みの Chrome を使って読み取るときに貼り付ける。

---

Instagram @riko_jitu（ログイン済みの Chrome）の、次のリールのコメントを読み取って表にまとめてください。

対象:
1. 早稲田理工で1番賢い入試方式はこれ（9/22）https://www.instagram.com/reel/DdlgqffJmXu/
2. 【大学別】同じレベルと言われた時の早稲田理工生の反応の違い（9/19）https://www.instagram.com/reel/DddsLuGxDko/
3. （余裕があれば）【受験勉強】文系と理系の違いPart3（9/23）https://www.instagram.com/reel/DdoD4p3pk-L/

ルール:
- 見るだけ。コメントへの返信・いいね・削除・非表示・投稿の編集など、アカウントを変える操作は一切しない。
- パスワード入力や二段階認証が必要になったら、そこで止めて私に知らせる。
- コメント主のユーザー名は書かない（「視聴者A」などにする）。

出力:
- 動画ごとの表: No｜コメント本文（長ければ要約）｜種類（共感／反論・ツッコミ／質問／ちゃむ・れんとへの言及／その他）｜いいね数（見えれば）
- 動画ごとのまとめ: 種類ごとの件数、目立つ意見を3つまで
- ちゃむ・れんとの名前や性格に触れたコメントがあれば、必ず全部書き出す

出力した表は、クラウドの管理セッションに貼り付けて「3 分析 → コメント記録」に反映する。
