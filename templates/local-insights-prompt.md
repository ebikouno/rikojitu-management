# ローカルチャット用プロンプト（Instagram インサイト取得）

Claude デスクトップアプリ（Claude in Chrome／パソコン操作が使える環境）で、Instagram にログイン済みの Chrome を使ってインサイトを読み取るときに貼り付ける。クラウドのセッションでは Instagram へのログインができないための代替手段。

---

Instagram の @riko_jitu（ログイン済みの Chrome）のインサイトを読み取って、表にまとめてください。

ルール:
- 見るだけ。投稿・編集・削除・コメント返信・設定変更など、アカウントを変える操作は一切しない。
- パスワード入力や二段階認証が必要になったら、そこで止めて私に知らせる。

手順:
1. 新しいタブで https://www.instagram.com/riko_jitu/ を開き、プロフェッショナルダッシュボード（またはインサイト）を開く。
2. アカウント全体（直近30日）: フォロワー数、閲覧数、リーチしたアカウント数、インタラクション数、プロフィールのアクティビティ、フォロワーの年齢・性別・地域・アクティブな時間帯。
3. 直近のリール12本それぞれ: タイトル（キャプション冒頭）、投稿日、再生数（閲覧数）、リーチ、いいね、コメント、保存、シェア、平均視聴時間、視聴率（またはスキップ率）、フォロー数、フォロワー／フォロワー以外の割合。
4. 取れなかった項目は空欄にして「取得不可」と書く（0 と書かない）。
5. 結果は次の形で出力する:
   - アカウント全体の表（項目｜値｜期間）
   - リールの表（1行＝1本、上の項目を列に）
   - 気づいたこと3点（数字から言えることだけ）

出力した表は、クラウドの管理セッションに貼り付けてシートに反映する。
